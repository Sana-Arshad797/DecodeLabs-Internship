# Student Grading Calculator

## About the Project

This is a simple Java Swing project that calculates a student's total marks, average, percentage, and grade. The program takes marks for five subjects, where each subject is out of 100. It also checks for invalid input and shows an error message if marks are not entered correctly.

## Features

* GUI made using Java Swing
* Takes marks of 5 subjects
* Calculates total marks
* Calculates average marks
* Calculates percentage
* Displays the student's grade
* Validates marks (0 to 100 only)
* Reset button to clear all fields

## Grade Criteria

| Percentage | Grade |
| ---------- | ----- |
| 90 - 100   | A+    |
| 80 - 89    | A     |
| 70 - 79    | B     |
| 60 - 69    | C     |
| 50 - 59    | D     |
| Below 50   | FAIL  |

## How to Run

1. Open the project in IntelliJ IDEA.
2. Make sure the file name is **GradeCal.java**.
3. Compile and run the program.
4. Enter marks for all five subjects.
5. Click the **Calculate** button to view the result.
6. Use the **Reset** button to clear all fields.
